# Module D — очень упрощённая SPA версия

Это самая простая учебная версия Module D:
- больше готового HTML;
- один CSS-файл;
- один JS-файл;
- без сборщиков, без компонентов, без сложной структуры;
- маршрутизация через hash (`#/`, `#/login`, `#/profile` и т.д.).

## Что нужно для запуска

1. Запустить API из Module C.
2. Открыть `index.html` через локальный сервер.
   Например, через VS Code Live Server.
3. Если API работает не по адресу `http://127.0.0.1:8000/api`, то в `app.js` поменять:

```js
const API_BASE = 'http://127.0.0.1:8000/api';
```

## Почему тут так мало JS

По твоей просьбе версия сделана максимально простой:
- HTML уже содержит почти все формы и страницы;
- JS только показывает нужный экран и отправляет запросы в API.

## Что поддержано

- регистрация;
- вход;
- выход;
- профиль;
- главная страница с фильтрами;
- мои объявления;
- создание / редактирование объявления;
- страница деталей;
- простая карусель картинок;
- показать телефон;
- покупка и продление услуг.
