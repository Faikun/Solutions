# Module D — инструкция с нуля

## 1. Что это за проект

Это клиентская часть для Module D.
Она работает с REST API из Module C.

## 2. Что нужно сначала

Сначала должен быть запущен Module C.
Например:
- Laravel API запущен на `http://127.0.0.1:8000`
- REST API доступен по `http://127.0.0.1:8000/api`

## 3. Как открыть фронтенд

Это обычный HTML/CSS/JS проект.
Можно открыть через:
- VS Code Live Server
- любой локальный HTTP-сервер

Пример через VS Code:
1. открыть папку проекта;
2. нажать `Open with Live Server`;
3. открыть страницу в браузере.

## 4. Где менять адрес API

Файл:

`app.js`

Строка:

```js
const API_BASE = 'http://127.0.0.1:8000/api';
```

Если у тебя другой адрес API, меняешь только её.

## 5. Как тут устроена навигация

Навигация сделана через hash:
- `#/` — главная
- `#/login` — вход
- `#/register` — регистрация
- `#/profile` — профиль
- `#/my-adverts` — мои объявления
- `#/create` — создание
- `#/details/ID` — детали
- `#/services/ID` — услуги

## 6. Как работает токен

После входа или регистрации токен сохраняется в `localStorage`.
При каждом запросе он автоматически отправляется в заголовке Authorization.

## 7. Почему версия упрощена

Здесь почти вся разметка написана заранее в `index.html`.
Поэтому начинающему проще понимать проект:
- сразу видно формы;
- сразу видно страницы;
- меньше JavaScript;
- легче повторить руками.
