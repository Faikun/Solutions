# Module E — Speed Task

Это учебная версия решений для Module E.

## Структура

- `Task-01` ... `Task-10` — отдельная папка на каждую задачу.
- В каждой папке лежит минимальный набор файлов.

## Важно

По ТЗ рабочий каталог должен содержать 10 подпапок от `Task-01` до `Task-10`, и каждая задача должна быть зафиксирована отдельным Git-коммитом.

## Ограничения

В PDF есть задания с референсами на видео и медиа:

- `wheel.png`
- `sample.mp4`
- видео для drip/button/menu/input

Эти медиа отдельно не были переданы, поэтому здесь сделаны максимально близкие учебные реализации, которые можно быстро адаптировать под точный референс.
